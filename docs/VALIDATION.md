# 実装・検証結果

初期検証：2026年10月17日。preview.2の互換性修正・再ビルド・テスト：2026年10月18日（日本時間）。Windows 10 x64 / 10.0.19045、.NET SDK 10.0.301で実施。

## 実装済み

- C# / .NET 10 / WPF、日本語、ライトテーマ、自作ベクターとEXEアイコン、配色リソース、角丸カード、最小720×500、Tab・アクセスキー・Ctrl+O。
- ドロップ・ファイル選択・引数での読み込み、保存前一覧、全選択・解除、選択保存、保存先を開く、インライン状態表示。
- 解析・保存・レジストリをUIから分離。StrictモードのMimeKitLite公開APIでTNEF本体を解析し、通常のファイル添付だけを抽出。本文を展開・表示しない。
- 件数・サイズ・属性・プロパティ等の上限、チェックサム・長さ検証、悪意ある名前の補正、CreateNewによる衝突回避、保存先のジャンクション拒否と移動防止。
- HKCUだけの右クリック登録・解除、所有キー保護、移動後の再登録案内、Shell通知。初回起動時の自動登録はなし。
- 本体のMIT通知と第三者ソフトウェアの通知をEXEへ埋め込み、設定から閲覧可能。通信・アップロード・テレメトリー・添付内容のログ・自動実行はなし。

## 意図した制限

埋め込みメール・OLE・参照添付・MAPI Object型の保存、MIMEメール全体の読み込み、Windows 11最上位コンテキストメニューへのCOM/MSIX統合、暗いテーマは対象外です。EXEのパスに `%` を含む場合の登録は安全のため拒否します。保存先の祖先にリンク／ジャンクションがある場所は利用できません。
