# Winmail Extractor v1.0.0-preview.2

## 修正内容

通常の添付ファイルが入っているにもかかわらず「TNEFの内容が破損しているか、対応していない形式です」と表示されるケースを修正しました。

使用しない補助プロパティの直後に名前付きMAPIプロパティがあると、MimeKit 4.18.1の暗黙の読み飛ばし処理が次のタグをデータ長として判定する場合がありました。補助情報を上限のある生データストリームで明示的に消費し、内容を解釈・展開せずに次へ進めるようにしました。

Strictモード、チェックサム・長さ・件数・サイズの検証は維持しています。破損データを無条件で許容する変更は行っていません。解析できない場合のメッセージも、ファイル破損とアプリの未対応を区別できる表現へ変更しました。

## ダウンロード

Assetsの **WinmailExtractor.exe** をダウンロードしてください。Windows x64用、.NETランタイム同梱の単一EXEです。旧版を終了してから置き換えてください。同じ場所・同じ名前で置き換えれば、右クリック連携の登録先パスは変わりません。

## 検証

- 個人情報を含まない合成データで同じ失敗を再現し、文字列・Unicode・バイナリの3ケースを回帰テストに追加。
- 使用しない補助プロパティでも不正な長さを拒否するテストを追加。
- Releaseビルドで警告0・エラー0、自動テスト50件成功。
- 提供された実ファイルを端末内だけで検証。通常のPDF添付1件を抽出し、TNEF内の元データとのバイト一致を確認。
- 実ファイルや添付内容・ファイル名はリポジトリにもReleaseにも含めていません。

Windows 11実機の右クリック操作、OSのDPI変更、ランタイム未導入の別PC、EXE署名などの未確認事項は継続しています。詳細は `docs/VALIDATION.md` を参照してください。
