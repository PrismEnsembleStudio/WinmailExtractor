# Winmail Extractor v1.0.0-preview.1

`winmail.dat` から添付を端末内で取り出す、日本語WPFユーティリティの初回プレビュー公開です。

## ダウンロード

Assetsの **WinmailExtractor.exe** を任意のローカルフォルダーへ置いて起動してください。Windows x64向け、インストーラー不要、.NETランタイム同梱です。

フォルダーへDLLを配置する必要はありません。.NET/WPFは実行時にWindowsの一時フォルダーへ展開・キャッシュされます。EXEは未署名です。

## 主な機能

- ドロップ・ファイル選択・引数からの読み込み、添付一覧と選択保存
- 既存ファイルの上書き防止、危険な名前の補正、サイズ・件数制限
- 現在のユーザーのみの右クリックメニュー登録・解除
- 外部へのアップロード・メール接続・添付の自動実行なし

## 検証と制限

Windows 10 x64でReleaseビルド（警告0）、自動テスト46件、EXE単体の5パターンの起動を確認しました。Windows 11実機での右クリック起動、実際のドラッグ＆ドロップ・OSダイアログ、DPI変更、ランタイム未導入PC、実メールでの受入確認は残っています。

埋め込みメール・OLE・参照添付・MAPI Object型は未対応です。EXEパスに `%` を含む場合の右クリック登録と、祖先にリンク・ジャンクションがあるフォルダーへの保存は拒否します。

不具合や改善提案はIssuesへお寄せください。**実メール・添付内容・個人情報は投稿しないでください。**
